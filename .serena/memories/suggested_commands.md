# Suggested commands

Run in `tutorial-local-hardhat/`:

- `npm install` — install pinned lockfile dependencies.
- `npm run build` — compile contracts and type-check the project through Hardhat.
- `npm test` — execute Hardhat's Solidity and Node test suites.
- `npx hardhat test solidity` / `npx hardhat test nodejs` — target one test suite.
- `npm run deploy` / `npm run send-tx` — execute Hedera-network scripts; set `HEDERA_RPC_URL` and `HEDERA_PRIVATE_KEY` first.
